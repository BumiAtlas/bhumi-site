# Bhumi.ai.id

Situs informasi tentang data pertanahan Indonesia: peta persil ATR/BPN, cek sertifikat dan NIB, HGU, konsesi, zonasi RDTR, risiko banjir, perbandingan aplikasi, dan MCP untuk asisten AI.

Situs: https://bhumi.ai.id

- `index.html`: semua fitur dalam satu halaman
- `perbandingan.html`: Bhumi ATR/BPN vs Perare vs BumiAtlas
- `mcp.html`: 11 fungsi MCP, alamat server dan cara menyambungkan

Peta dan datanya dijalankan oleh [BumiAtlas](https://bumiatlas.com). Server MCP: `https://bumiatlas.com/mcp/bhumi`.

Situs ini independen dan tidak berafiliasi dengan Kementerian ATR/BPN. Data berupa salinan sumber publik, bukan bukti kepemilikan atau izin yang sah.
